ShotgunKeystroke

Every keystroke on your Mac fires a shotgun. Keyboard typing sound effects with real recoil — a free, open-source menu bar app.

Download for macOS View on GitHub

Features

  • 🔫 / 🕊️ One-click ceasefireMenu bar toggle — the icon dims when the guns are down.
  • Volume 10–100%From polite office skirmish to "the neighbors are calling someone."
  • Custom soundsSwap the shotgun for any WAV/MP3/M4A. Ducks, dial-up, your call.
  • Modifier keys & hold-to-repeatOptional. ⌘S has never felt this dramatic.
  • Launch at loginYour Mac boots, the shotgun racks. Settings persist.
  • Tiny & native~1 MB Swift app. No Electron, no dependencies, near-zero idle CPU.

Privacy: ShotgunKeystroke never reads which key you pressed — only that a key went down. No key codes, no logging, no network access. The source is one small file; audit it yourself.
