01

It plays a sound when you type. That's the product.

Most keyboard sound apps try to make a laptop feel like a mechanical keyboard: soft thocks, clicky blue switches. ShotgunKeystroke goes the other way. Every key-down anywhere on your Mac, whether you're in your editor, in Slack, or in the Spotlight bar, plays a short, loud shotgun blast.

It lives in the menu bar, not the Dock. There's an on/off switch, a volume slider, and a menu item that swaps the shotgun for any audio file you like. Holding a key down doesn't turn into a machine gun unless you ask it to. Settings survive restarts, and it can launch at login.

It's native Swift with no third-party packages. The built app is about 200 KB and sits at near-zero CPU while you're not typing.

02

How it works

  1. It asks for one permission.

    macOS won't let any app see keystrokes outside its own windows without Input Monitoring. Accessibility isn't enough: without Input Monitoring, macOS only passes along modifier keys. The app asks on first launch and shows a ⚠️ item in its menu until you say yes. It checks again every couple of seconds, so there's no relaunch after you grant it.

  2. It listens, and only listens.

    Keyboard events are picked up with a listen-only event tap (CGEventTap with .listenOnly). A listen-only tap can watch events go by. It can't change them, block them, or type anything on your behalf.

  3. It doesn't look at the key.

    This is the entire decision, straight from AppDelegate.swift:

    case .keyDown:
    guard Settings.isArmed else { return }
    let isRepeat = event.getIntegerValueField(.keyboardEventAutorepeat) != 0
    if isRepeat && !Settings.fireOnRepeat { return }
    engine.fire()

    No key code, no character. There's nothing to log because it never asks which key it was.

  4. Eight barrels.

    The sound engine loads eight copies of the blast up front and rotates through them. Type fast and the shots overlap instead of each one cutting off the last.

03

It hears that you typed. Not what.

What it reads

  • That a key went down
  • Whether it was an auto-repeat from a key being held
  • Which modifier keys changed, for the optional modifier sounds

What it never touches

  • Key codes or characters
  • The network. There's no networking code in it at all.
  • Your disk, apart from its own settings
  • Anyone else's input. The tap can't modify or block events.

The app is signed with Apple's hardened runtime, so other programs on your Mac can't inject code into it and borrow its Input Monitoring permission.

You don't have to take this page's word for any of it. AppDelegate.swift is under 400 lines, and the security model is written up in SECURITY.md.

04

Install

Download

  1. Get ShotgunKeystroke.app.zip from GitHub Releases.
  2. Unzip it and drag the app into Applications.
  3. The release isn't notarized, so macOS blocks the first launch. Right-click the app, choose Open, then Open again. Or clear the quarantine flag: 
    xattr -dr com.apple.quarantine /Applications/ShotgunKeystroke.app
  4. Allow it under System Settings → Privacy & Security → Input Monitoring.

Build it yourself

You'll need macOS 13 or later and either Xcode or the Command Line Tools (xcode-select --install). Building it yourself means you're running exactly the code you just read. 

git clone https://github.com/Piyushsomething/ShotGunKeystroke.git
cd ShotGunKeystroke
./build.sh
open build/ShotgunKeystroke.app

Rebuilding resets the permission, because each build gets a new ad-hoc signature. Run bash scripts/setup-signing.sh once to keep the same signature between builds.

05

Questions people actually ask

Isn't this basically a keylogger?

It needs the same permission a keylogger would, which is exactly why the key-handling code is five lines long and public. It never reads which key you pressed, and it has no way to send anything anywhere.

Can I use a different sound?

Yes. Choose Sound File… in the menu takes any WAV, MP3, M4A or AIFF. If a file can't be decoded, the app keeps the current sound and tells you. Reset to Shotgun Blast brings the shotgun back.

What happens when I hold down backspace?

One shot. Auto-repeat is ignored by default. Turn on Fire on Key Repeat if you want the machine gun.

Does it work with an external keyboard?

Yes. It listens to keyboard events at the system level, so it doesn't matter which keyboard sent them.

⌘ and ⇧ make noise but letters are silent. Why?

The Input Monitoring grant belongs to an older copy of the app, which usually happens after a rebuild. Remove ShotgunKeystroke from the Input Monitoring list and add it again, or rebuild with ./build.sh, which clears the stale grant for you.

Windows? Linux?

No. It's built on macOS APIs (AppKit and CoreGraphics event taps) and only runs on a Mac.

How do I make it stop?

Click the 🔫 in the menu bar and choose Ceasefire. The icon turns into a dimmed 🕊️. Quit is at the bottom of the same menu.
